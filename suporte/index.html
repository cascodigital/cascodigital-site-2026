§01 — Como funciona

Três passos.
Um minuto.

P.01 / DOWNLOAD

Baixe o agente

Clique no botão acima. O Windows pode avisar que é um arquivo baixado da internet — pode manter o download.

P.02 / EXECUTE

Abra o arquivo

Dê dois cliques em suporte_casco.exe. Nada é instalado: a janela abre e mostra um ID e uma senha.

P.03 / CONECTE

Passe os dados

Informe o ID e a senha ao técnico pelo WhatsApp ou telefone. Você acompanha tudo o que é feito na sua tela.

!

Só execute este programa durante um atendimento combinado com a Casco Digital. A senha muda a cada vez que o agente é aberto e o acesso termina quando você fecha a janela. Ninguém consegue se conectar sem os dados que aparecem na sua tela.
